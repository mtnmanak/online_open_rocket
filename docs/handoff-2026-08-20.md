## Hard-won things worth not relearning

- **The purge list nearly missed 46 MB.** The RockSim files lived FLAT at
  `docs/2D_3D_Models/Rocksim_*` before the v0.043 subfolder reorganization —
  `--invert-paths` on current paths only would have left every blob reachable from
  v0.041/0.042 commits. A verifier enumerated all historical paths per blob and re-ran
  the corrected purge on a scratch clone first. **Purging by current path is not
  purging.**
- **An unconditional "bridge everything" is a perf bug.** Serializing all 58 extra
  series on every sim measured +44% wall-clock; the summary/full option keeps the
  payoff and drops the cost. Measure old-vs-new artifacts, not intuitions.
- **`tc` (TYPE_COMPUTATION_TIME) is wall-clock noise** — dumping it made same-seed
  outputs differ. Excluded from `full`; determinism is again byte-exact (proven by the
  CSV re-fly comparing branch finTime to the shown flight).
- **javac on this machine compiles with cp1252** — a ρ in a Java comment raised
  "unmappable character" and Gradle STILL printed BUILD SUCCESSFUL with a stale
  teavmClasses. After any encoding-adjacent Java edit: `gradlew clean`, full rebuild,
  and verify the new code path is in the artifact before difftest.
- **Vite's dep cache serves stale engine kernels.** After an engine rebuild,
  `node_modules/.vite` kept serving the old artifact (a CSV showed `tc` that the new
  kernel never emits). Dev-serve with `--force` once after any vendor artifact change.
- **The kernel's wind direction is meteorological** (an "east wind" blows FROM the
  east) and the stepper ADDS wind to rocket velocity — downwind is compass 270° for the
  default π/2 direction. The e2e drift test caught the sign error a plausible-sounding
  90° assumption produced. `θl` IS a compass bearing already (`atan2(x, y)`, 0 = north).
- **Writing files with Python `io.open(...,'w').write()` truncates on a failed encode**
  (a surrogate-pair escape killed version.ts mid-write). Encode to bytes FIRST, write
  bytes, `os.replace` — or use the Write tool.
- **Lane isolation by file set works until it doesn't**: one lane edited another's file
  (orkFile.ts) mid-session; the golden round-trip test caught the resulting
  desktop-inexact export. The fix was adopting one field name and desktop-exact
  semantics — goldens are the cross-lane referee.
