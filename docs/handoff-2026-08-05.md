## 4. Nuances & gotchas (new this session — see 08-04 handoff for older)

- **JSON.stringify(Infinity) → null.** Plugged delays persist as the
  string "Infinity" via replacers in simStore AND session.ts. Any new
  persisted field that can be Infinity needs the same treatment.
- **RockSim rounds the same dimension differently between copies** —
  never exact-match-group imported geometry; use tolerances.
- **RockSim stores NO fin interleave angle** (RadialAngle 0 on everything)
  — its renderer fakes it. Import-side de-collision is ours.
- **setState updaters run after the handler returns** — capture mutable
  refs into locals first (v0.035 crash).
- **The shared engine handle is sacred**: anything that flies alternates
  (batch) must build its own handle from the tree. There is no
  clear-motor API and no per-handle dispose; handles free on the next
  resetEngine (App build memo).
- **fairing/spill-hole lowering lives in `treeModel.engineTree()`** — any
  new app-level physics concept goes there, keeping ids stable.
- **Eric's real .rkt files are gold for verification** — paths in
  `G:\Documents\Dropbox\Rocksim Designs\Scratch Builds\` (Darkstar, Ultra
  Neon). Verified via throwaway vitest files reading the absolute path
  (create → run → DELETE; never commit).
- **deg schema fields auto-convert to radians** via PropertyPanel's LEGACY
  map — new angle fields just use unit 'deg'.
- **Sheet names in xlsx**: ≤31 chars, no `: \ / ? * [ ]` — sheetsToXlsx
  sanitizes; keep it that way.
- The tolerant cluster grouping + de-collision + reconstruction all run in
  importRkt in ORDER: convert → reconstructClusters → deCollideFins.
