- **18. Camera shrouds — discuss (I have a concrete proposal).** I agree with your proposal and phasing. I very much (and I have heard many users echo) want a real shroud component that is calculated into the CP and drag of the rocket. A camera shroud on a really large rocket may make no difference, but it is difficult to believe that a camera shroud on a 4" diameter rocket would have no effect on CP and drag. If we have to develop new physics models for this, so be it. We will be unique with this capability compared to the other rocket sims. I agree with your assessments on how to export it and how it would be handled by other apps. For the visual of it, since it is on the outside of the rocket, I want to make sure it is depicted with a solid line and should have all the normal exterior options like color, surface finish, etc.
- **21. Inner components all look identical — BASIC VERSION SHIPPED + options.** I like the miniature glyphs option for parachutes, mass objects, centering rings and shock cords. I also like fill patterns for components where it would be appropriate (like bulkheads). The screen may get busy, but I think it would go a long way towards the user understanding which component is which on the display. Another feature we should add - when the user selects a component in the left components tree, it should highlight that component on the display. Conversely, if a user clicks on a component on the display, it should select that component in the left-hand component tree (the components on the display should be clickable, not just draggable).
