# OpenRocket Online — Test Run Notes (Part C)
**Date:** 3 July 2026

## Blockers
- The input for **maximum motor length** should live in the main dialog boxes, not in the motor chooser. It's a fundamental physical property of the rocket. Having it in the motor chooser dialog also prevents this attribute from being factored into **batch motor simulations**.

## Annoying
- Launch simulation output needs more information. At minimum, in the **CSV download**, add:
  - Motor type (reload, single-use, etc.)
  - Propellant type
  - Motor case (if it's a reload)
- **Clean up motor designations:**
  - **Cessaroni (CTI)** motor designations include extra text before the actual designation — this pre-text should be stripped. Example: `381I224-15A` should display as just `I224-15A`.
  - Some other manufacturers (at least **Aerotech** and **Loki**) sometimes prepend `HP-` to the motor designation — this should also be stripped.
  - **CSV output columns** for launch simulations should be labeled and ordered as follows (remaining columns can follow in any order):
    1. Designation
    2. Apogee (ft)
    3. Velocity (mph)
    4. Manufacturer
    5. Diameter
    6. Type
    7. Propellant
    8. Case
    9. T:W
    10. Guide (mph)
    11. Accel (Gs)
    12. Delay (s)
    13. Pad Weight (weight with motor installed) (g)
    14. Recovery Weight (weight after motor burnout) (g)
- Why is there an error notification on every file saying: *"Motor "G80T" isn't built-in — pick it via thrustcurve.org search"*?
- **Saved simulations should be clickable** — clicking one should load that simulation's info into the launch report section.
