- 2D Image (saves either a .png, .jpg, .xbm, .xpm, .pnm, or .bmp file)
- 3D Model (saves as a .mtl + .obj set of files, or single .mtl file, or .wrl file, or .rib file, or .iv file, or .oogl file, or .x3d file, or ,pov file)

all the file formats should be taken with a grain of salt since these functions have existed in Rocksim for many years. It may not be a good idea to simply recreate these file export options.
